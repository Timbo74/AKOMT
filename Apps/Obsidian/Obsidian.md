## Keyboard Shortcuts

| Action               | Windows / Linux    |
| -------------------- | ------------------ |
| **Quick Switcher**   | Ctrl + O           |
| **Command Palette**  | Ctrl + P           |
| **New Note**         | Ctrl + N           |
| **Toggle View**      | Ctrl + E           |
| **Bold**             | Ctrl + B           |
| **Italic**           | Ctrl + I           |
| **Insert Link**      | Ctrl + K           |
| **Global Search**    | Ctrl + Shift + F   |
| **Graph View**       | Ctrl + G           |
| **Undo**             | Ctrl + Z           |
| **Redo**             | Ctrl + Shift + Z   |
| **Close Tab**        | Ctrl + W           |
| **Reopen Tab**       | Ctrl + Shift + T   |
| **Navigate Back**    | Ctrl + Alt + Left  |
| **Navigate Forward** | Ctrl + Alt + Right |
