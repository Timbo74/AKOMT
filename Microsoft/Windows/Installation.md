# Installation

## Install with local account.

Open the Command Prompt (Press ```Shift + F10```) and type the following command:

``` terminal
OOBE\BYPASSNRO
```

Your computer will automatically restart.  Disconnect your PC from the Internet.

Once the PC reboots back to the setup screen, go through the initial language and region prompts again until you reach the network screen.
 * Click "I don't have internet" (if your device is plugged into Ethernet or Wi-Fi, unplug the cable or disable the wireless adapter first).
 * Choose "Continue with limited setup" if prompted.
