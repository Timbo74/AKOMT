### Basic Link
```markdown
[[Note Title]]
```
### Link with Alias
```markdown
[[Note Title | Display text goes here]]
```
### Link to Specific Section or Block
```markdown
[[Note Title#Heading]]

[[Note Title^block-id]]
```
